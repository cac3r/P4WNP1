
JS HID scripts directly compatible with P4WNP1 A.L.O.A. 

recon.js
- Run Local (Windows) and/or Domain (AD) reconnaissance commands and redirect output to files, save files to selected extraction storage (USB mass storage or External drive)  

user_files.js
- Extract files from specified User directories such as Desktop, Documents, Downloads and more. Specify also file types to extract such as pdf, txt, docx and more. Save files to selected extraction storage (USB mass storage or External drive)

cred_dump.js 
- Extract credential files (SAM, Security, System) or hashes (with Mimikatz). Save files to selected extraction storage (USB mass storage or External drive)

revshell.js
- Execute reverse shell code (low success rate on Win 10 and 11. AV / AMSI ...)

all_in_one.js
- A combination of all above inside one script
